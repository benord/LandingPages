## ☕ Origen & Co. | Prototipo Web para Cafetería & Bistro

Maqueta web moderna, ligera y responsiva (*Mobile-First*) para cafetería y restaurante local, desarrollada en un único archivo con **HTML5**, **Tailwind CSS (CDN)** y **JavaScript Vanilla**.

### 🚀 Características
- **Encabezado interactivo:** Logotipo vectorial, nombre, estado dinámico en vivo ("Abierto Ahora"), ubicación y horario.
- **Buscador en tiempo real:** Filtra rápidamente cafés, bebidas, platos y postres por palabras clave.
- **Categorías interactivas:** Pestañas desplazables para explorar el menú por secciones (*Cafés & Bebidas*, *Comidas / Platos*, *Postres*, *Especiales*).
- **Tarjetas de productos:** Fotografías de alta calidad, descripción, insignias especiales, precio en COP y control de cantidades.
- **Carrito Flotante:** Barra persistente en la parte inferior que refleja la cantidad de ítems y el subtotal acumulado.
- **Modal de Checkout:**
  - Control para ajustar o eliminar productos.
  - Selección de modalidad: *A Domicilio* (con costo de envío) o *En Mesa / Local*.
  - Campo de notas/instrucciones para cocina.
  - Formulario de datos del cliente (Nombre, Dirección/Mesa, Teléfono).
  - Selección de método de pago (Nequi / Daviplata o Efectivo).
- **Integración con WhatsApp:** Envío automático del pedido formateado y desglosado vía WhatsApp API (`https://wa.me/...`).

### 🛠️ Tecnologías
- HTML5 Semántico
- Tailwind CSS (vía CDN)
- JavaScript Vanilla (sin dependencias pesadas)

### 📦 Uso local
Simplemente abre el archivo `index.html` en cualquier navegador web.
